We currently support only a limited set of type annotation patterns. At the moment, the value of a ``JSONObject`` must be bound by ``JSONValue`` (a primitive other than ``bytearray``, a constrained primitive thereof, ``JSONValue``, ``JSONArray`` or another ``JSONObject`` satisfying the same bound), but the property 'value' of the class 'Something' has type: JSONObject[str, Some_class]. Please contact the developers if you need this functionality
